# ChatGPT 相机 0.1.0 测试版

这套工具由安卓相机和 Windows 接收端组成，面向同一局域网里的手机与电脑。照片传到电脑后，接收端尝试将它附加到前台 Codex 的输入框，消息仍由你发送。

**当前交付状态：安装包和加密传输测试已通过；真实手机拍摄及自动进入 Codex 附件区尚未验收。无法可靠识别对话时，程序会保留照片供手动粘贴。**

## 开始使用

1. 在 Windows 10/11 x64 电脑上解压 `Windows-Receiver-0.1.0.zip`，双击 `ChatGPTCameraReceiver.exe`。程序自带运行环境，无需另装 .NET。
2. 将 `ChatGPT-Camera-0.1.0.apk` 传到安卓手机并安装。要求 Android 8.0 及以上；这是供个人测试安装的 debug 签名 APK，不是应用商店发行版。
3. 手机与电脑连接同一 Wi-Fi；电脑有线连接到同一路由器也可以。接收端下拉框选择该网络的电脑 IPv4 地址。
4. 手机打开相机应用，授予相机权限，点击“配对电脑 → 扫描电脑上的二维码”。也可以使用“粘贴配对内容”。成功配对前不会启用拍摄传输按钮。
5. 将电脑上的目标 Codex 对话切到前台，保持当前对话不变，在手机按“拍照并传输”。拍摄请求抵达电脑的时刻决定接收目标。
6. 照片出现于附件区后，再自行点击 Codex 的发送按钮。

电脑接收端关闭窗口后会收起到系统托盘，仍然接收照片。双击托盘图标重新打开；右键托盘图标选择“退出”才会停止接收。

## 看懂状态

| 状态 | 含义及操作 |
| --- | --- |
| 已附加 | 接收端观察到输入框新增附件；仍需你发送消息。 |
| 待手动插入 | 前台不是 Codex、会话已改变、记录超时或无法识别输入框/会话。选择照片，点击“复制所选照片”，回到正确的输入框按 Ctrl+V。 |
| 请检查附件 | 程序曾尝试粘贴，但不能确认附件出现；先检查输入框，再决定是否手动粘贴，避免重复。 |
| 手机提示未确认送达 | 照片保留在手机中；恢复连接后点击“重试待传”。同一照片重试不会重复触发自动粘贴。 |

补传时不会把新打开的对话冒充成拍摄时的目标。电脑重启后，旧的窗口和会话标识会失效，待处理照片改为手动插入。

## 连接不通时

- 检查接收端仍在运行，并核对所选地址。VPN 或虚拟网卡可能出现多个地址；使用与手机同一网络的地址。
- 接收端监听 TCP 47831。若 Windows 防火墙询问是否允许连接，需要你为信任的专用网络允许该程序；交付程序没有自动修改防火墙规则。
- 访客 Wi-Fi、热点隔离或路由器的设备隔离可能阻止手机连接电脑。换到允许设备互通的同一路由器网络。
- 若配对身份校验失败，检查手机日期与电脑接收端，再重新扫描该电脑的二维码。应用不会跳过证书指纹校验。

## 照片与配对数据

- 电脑照片保存在 `%LOCALAPPDATA%\ChatGPTCamera\photos`，可以从接收端打开。配对身份保存在同级 `pairing.json`，不要分享这个文件或配对二维码。
- 手机照片保存在应用专用存储；已经送达的照片和未送达照片都会保留，卸载或清除应用数据会移除这些本地副本。第一版没有相册管理界面。
- 传输使用 HTTPS 和二维码里的证书 SHA-256 指纹，不需要 ChatGPT 登录信息或 API Key，也没有额外的云端照片中转。之后在 Codex 里发送附件仍按 Codex 自身行为处理。
- 自动粘贴以及“复制所选照片”都会将图片放到 Windows 剪贴板，覆盖原来的剪贴板内容。

## 已知限制

- 自动附加依赖 Windows 辅助功能树暴露可识别的 Codex 输入框及带唯一标识的选中会话；界面版本、多个可编辑区域或新对话界面可能无法识别，届时保留照片。没有通过修改 Codex、注入内部接口或启用远程调试绕过这一点。
- 相机使用默认后置镜头和连续自动对焦，第一版为竖屏界面，没有镜头切换、闪光灯或缩放控制。扫码、预览方向和机型适配尚未实机验证。
- 单张上传上限 20 MB、解码尺寸上限 4000 万像素；拍摄优先选择不超过 500 万像素的 JPEG。
- 自动附加目标记录有效期 2 分钟，超时保留照片。局域网延迟会造成快门时刻与电脑记录目标时刻的差异。
- 接收目录最多登记 1000 次拍摄请求；长期使用需自行整理该目录并重启程序。当前没有自动清理功能。
- Windows 可执行文件未做商业代码签名；APK 为 debug 签名。本版本用途是个人实机测试。

## 首次验收

先用一张无关紧要的测试照片验证正常传输，观察是否真的出现附件。然后分别测试：拍摄后切换对话、切换到其他程序、断网后补传、接收端重启。检查图片方向、是否误投、是否重复和显示的状态是否准确。尚未出现附件时，不应将“照片已到电脑”视为自动附加成功。

源码和详细验证记录见 `ChatGPT-Camera-Source-0.1.0.zip` 与 `验证记录.md`。
