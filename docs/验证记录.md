## 尚未通过实机验收

- Android 真机没有连接；本机 AVD 配置存在，但它引用的 Android 34 系统镜像缺失，模拟器未启动成功。
- 安卓预览、二维码识别、真实拍照、EXIF 方向及机型差异没有运行时验证。
- 当前 Codex 界面的会话识别与实际附件出现没有现场验证。桌面 Computer Use 技能限制直接自动操作该应用；本次只检查了新建接收端的 UI。
- 真实局域网、Windows 防火墙放行及快门到附件出现的延迟没有测量。
- 目标检查与按键注入之间不是系统级原子操作，需要实测拍摄期间切换对话、窗口和焦点的行为。

## 已修复的构建/集成问题

- .NET Windows 桌面项目的命名空间与初始化 API。
- 证书重复导出导致的私钥导出异常。
- Windows Schannel 不支持 ephemeral key 引发 TLS 握手失败；改用用户密钥存储后协议测试通过。
- 安卓 SDK 不提供 Files.readString/writeString，改用 Android 8.0 起可用的字节读写 API。
- Android 系统栏 Insets 的版本保护范围。
- 预览保持纵横比、接收端按 EXIF 方向复制图片、断网时先保存照片再排队传输。

请按 `使用说明.md` 的首次验收步骤完成最后一环。在没有观察到附件前，测试版仅能确认照片传输功能已经验证。
