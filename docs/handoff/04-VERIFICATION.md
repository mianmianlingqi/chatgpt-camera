原始验证记录见 docs/验证记录.md。该记录是历史执行结果，本次文档同步不代表再次运行全部测试。

## 明确未测

没有连接真实 Android 设备；已有 Pixel_5_API_34 AVD 缺少引用的系统镜像，模拟器未启动成功。
没有验证真实拍照/扫码、预览方向、EXIF、前后摄差异、真实局域网和防火墙。
没有观察到照片在真实 Codex 的当前输入框出现，也没有测量快门到附件延迟。

当时的 Computer Use 技能限制直接操作目标 ChatGPT 桌面应用，所以只测试新接收端 UI。此为当时工具约束，不是产品永久限制；接手 agent 应检查当前工具与权限，不要照抄旧限制作为新结论。原机临时 app-reference 是研究材料，不属于可发布项目源码；ProseMirror/tab 标识的源码线索不等价于真实 UIA 暴露。

## 已处理的历史问题

- Windows 项目命名空间/初始化 API 构建错误已修正。
- 证书重复导出触发私钥不可导出异常；持久保存已导出的 PFX。
- Schannel 在 EphemeralKeySet 下 TLS 握手失败；切换 UserKeySet 后协议测试通过。
- Android 不提供 Files.readString/writeString；改用 API 26 可用字节读写。
- 系统栏 Insets 版本保护、预览比例、电脑复制图片 EXIF 方向、断网先保存再排队已实现；后三项仍需真实相机行为验证。

## 下一轮可复现实机验收

1. 记录 APK/EXE SHA、Git SHA、安卓机型/版本、Windows 与 Codex 版本、局域网类型。用无敏感内容的测试卡。
2. 启动接收端，手机与电脑同网，选择可达 IPv4，处理用户认可的防火墙访问并扫码。预期健康连接成功。
3. 在 Codex 打开测试会话并保持编辑框可用，拍摄。观察手机保存、电脑 JPEG、附件缩略图三处；记录时间戳。不得只根据手机“已传输”宣布通过。
4. 手动发送测试照片由用户控制；自动链路不得发送消息。核对图片内容和方向、原文字是否保留。
5. 拍摄/上传中切换会话、应用、焦点或保持按键；预期目标不确定时进入队列，不误贴新会话。记录任何竞争窗口。
6. 断网拍摄、恢复后补传；预期本地 JPEG 保留且不绑定新会话。同 ID 同内容重试无重复附件。
7. 上传过程中重启接收端、两分钟后返回、粘贴结果不明；预期保留、明确提示并避免自动重复。
8. 切换前后摄/旋转场景、后台再前台、拒绝再授予权限、多次快速拍摄、扫码失败、IP 变化重新配对；记录结果。
9. 最后记录快门→落盘→传输→实际附件的分段耗时，至少重复多次报告样本数、范围与失败次数，不承诺未经测量的“立即”。
