# 需求与决策

## 确认目标

安卓应用拍摄照片后，尽快传到拍摄时用户正在打开的 Windows Codex 输入框，作为附件等待用户发送。截图显示的是桌面 Codex，接收端不是安卓 ChatGPT 分享菜单，也不是独立 API 对话。

## 当前实现的决策

- Android Java Camera2 原生预览拍摄，ZXing 扫描接收端配对码。Windows C# .NET 8 WinForms 提供接收服务、二维码、队列和托盘。
- 局域网直连，HTTPS + 配对证书 SHA-256 指纹固定 + 随机 Bearer token；没有中转云服务，也不需要 ChatGPT API key。
- 快门流程先发预留请求并保存原始目标，再上传已在手机落盘的照片。网络预留时刻与物理曝光并非严格同步，弱网需要验收。
- 自动粘贴前核对窗口、进程、会话、编辑框和目标年龄（两分钟以内），只按 Ctrl+V，不按 Enter。
- 无法证明目标一致、目标切换、过期、重启或结果不明时保存到队列。补传不得把新打开的会话当成原始目标。
- 重复上传同一 ID 与同一字节不重复注入；同一 ID 不同字节返回冲突。
- 仅支持 RFC1918 私网 IPv4 / 回环配对；不支持公网直连、主机名或 IPv6。正常接收服务监听全部 IPv4 地址，鉴权并不等于网络隔离。
- 调试签名 APK 是个人测试包。正式分发需要独立私有签名及升级策略。

## 发布授权

用户确认默认私有 GitHub 仓库 chatgpt-camera，并在 Notion 默认私有位置保存说明、安装包、验证记录和全部开发交接资料。GitHub 保存版本化源代码与大文件发行包，Notion 提供接手导航、详细档案和可下载源码/安卓 ZIP。Windows ZIP 超过 Notion 当前单次上传接口的 20 MiB 限制，使用 GitHub Release 下载链接。

## 后续变更准则

照片出现在正确附件列表才算完成核心体验。仅显示“已传输”、文件存在或发送了 Ctrl+V 均不算。
若 UIA 接口无法稳定识别，不应悄悄去掉会话保护来得到演示效果；先记录实际结构，提出可验证的新适配方式。
